# 🛡️ Network Forensics & PCAP Analysis Portfolio

Welcome to my Network Forensics and Traffic Analysis repository! 👋 
This repository serves as a personal portfolio where I document my write-ups, analysis steps, and findings from investigating various network packet captures (`.pcap`/`.pcapng`). 

The main goal is to track down cyber threats, analyze malware behavior, detect unauthorized access, and extract Indicators of Compromise (IoCs).

## 🛠️ Core Skills & Tools Demonstrated

Through these labs, I utilize industry-standard tools and techniques:
* **Packet Inspection:** Wireshark, Tshark, NetworkMiner.
* **Traffic Filtering:** Advanced Wireshark display filters (e.g., `http`, `tls.handshake`, `tcp.flags`).
* **Artifact Extraction:** Carving payloads, credentials, and certificates from PCAP files.
* **Threat Intelligence:** Leveraging CyberChef, VirusTotal, and URLhaus for IoC verification.
